# LOST.INTERNET 

**The Internet Never Forgets.**

LOST.INTERNET is an open-source AI-powered digital archaeology experience for exploring forgotten websites, technologies and internet culture.

## Features
- Curated digital-history archive
- Category filters
- Semantic search using an open-weight embedding model
- In-browser inference with Transformers.js
- Keyword fallback if the model cannot load
- Responsive dark interface

## Technology
- HTML, CSS and JavaScript
- Transformers.js
- Xenova/all-MiniLM-L6-v2

## Run locally
Open this folder in VS Code and launch `index.html` with the Live Server extension. Keep an internet connection for the model and fonts to load.

## Open-source AI
The app uses the `Xenova/all-MiniLM-L6-v2` sentence-embedding model through Transformers.js to compare the meaning of a search query with archive entries. The model runs in the browser; no paid AI API key is required.

## Important scope note
This is a curated discovery catalogue with links to historical references. It does not host recovered copies of the listed websites.
